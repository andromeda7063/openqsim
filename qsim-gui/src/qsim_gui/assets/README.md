# Toolbar icons

These SVG assets are from [Lucide](https://lucide.dev/), an open source icon
library. They are stored locally so the application does not need a network
connection to display them. The Lucide license is included in
`LUCIDE-LICENSE.txt`.

Icons used: `file-plus`, `folder-open`, `save`, `file-pen`, `undo-2`,
`redo-2`, and `play`.
